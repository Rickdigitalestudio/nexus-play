## 📋 Sobre o Projeto

O **Nexus Play** é um hub social de jogos 3D que combina:

- 🎮 **Jogos em destaque** - Carrossel 3D com títulos populares
- 🏪 **Loja virtual** - Catálogo de jogos e produtos
- 📚 **Biblioteca pessoal** - Suas coleções e progresso
- 📊 **Estatísticas** - Horas jogadas, conquistas e métricas
- 💬 **Chat** - Comunidade e conversas com amigos
- 👥 **Sistema de amigos** - Perfis e atividades

Built with HTML5, CSS3, JavaScript e Three.js para uma experiência imersiva 3D.

## 📦 Como Rodar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/Rickdigitalestudio/nexus-play.git

# 2. Acesse a pasta
cd nexus-play

# 3. Instale as dependências (se necessário)
# (O projeto é estático, não requer build)

# 4. Abra o index.html no navegador
# Ou rode o servidor local:
python -m http.server 8000
# Acesse: http://localhost:8000
```
